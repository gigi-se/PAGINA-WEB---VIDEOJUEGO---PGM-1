Rockstar-style React template
================================

This project is an original React template inspired by cinematic game landing pages (layout and behavior), **not** a copy of any copyrighted site. It uses original placeholder text and simple CSS.

How to run
----------
1. Unzip the downloaded file.
2. Run:
   npm install
   npm run dev
3. Open the local dev URL printed by Vite (usually http://localhost:5173).

Swap assets
-----------
Replace text, images, and videos in `src/components` and the `public` folder with your own assets.

Notes
-----
- This is a minimal Vite + React starting point (no Tailwind). If you want Tailwind, routing, or additional features (animations, video background, cookie banner, etc.), tell me and I'll add them.
